# WDPC — пульт для ПК в стиле Watch Dogs 📱→💻

Android-приложение (**APK готов**, папка `apk/`) управляет компьютером:
переключение окон (Alt+Tab, Task View), Пуск, закрытие/сворачивание окон,
навигация по переключателю окон стрелками.

## Варианты подключения

| Транспорт | Для какой ОС ПК | Что нужно на ПК |
|---|---|---|
| **Wi-Fi (TCP, порт 8721)** — рекомендуется | **Windows** | только запустить один скрипт `pc_server_win/wdpc_server.py` (ничего устанавливать не надо, если Python 3 уже есть) |
| Bluetooth SPP (без подтверждения пары) | Linux | `pc_server_linux/wdpc_server.py` + bluez |

## Быстрый старт (Windows)
1. Установите на телефон `apk/WDPC-Remote-v1.1.apk` (разрешите установку из неизвестных источников).
2. На ПК: скачайте папку `pc_server_win` и дважды кликните `run_server.bat`.
   - Если Python 3 нет — один раз поставьте из Microsoft Store (бесплатно). Это единственная «установка», библиотек не нужно никаких.
   - При первом запуске разрешите доступ в сеть для частного профиля.
3. Сервер покажет IP (например `192.168.1.50`) — введите его в приложении и нажмите «Подключить Wi-Fi». Телефон и ПК должны быть в одной сети.

## Почему нельзя «только телефон, ничего на ПК»?
Чтобы управлять клавиатурой ПК, телефон должен притвориться Bluetooth-HID-клавиатурой,
а Android запрещает приложениям выступать HID-устройством без root. Поэтому минимум
на Windows — один скрипт без зависимостей и установки. Альтернативы совсем без софта
на ПК: USB/BT-донгл, эмулирующий клавиатуру (отдельное «железо»).

## Структура
```
apk/                готовый WDPC-Remote-v1.1.apk (подписан)
android/            исходники приложения (gradle assembleRelease)
pc_server_win/      сервер для Windows (Wi-Fi/TCP, SendInput, без зависимостей)
pc_server_linux/    сервер для Linux (Bluetooth SPP через uinput + веб-режим)
```

## Протокол
Текстовые команды по строке: `KEY <vk> [DOWN|UP]`, `CHORD <vk1> <vk2> ...`, `PING`.
Для Windows коды — Virtual-Key (VK_TAB=9, VK_MENU=18, VK_LWIN=91 и т.д.).

⚠️ Не используйте с UAC-запросами и играми с античитом (SendInput туда не проходит, а запросы UAC игнорируйте — не отправляйте «слепые» клики).
