# WDPC server для Windows

Никаких библиотек и установок — только стандартный Python 3 (ctypes + SendInput).

## Запуск
1. Если Python 3 не установлен: `winget install Python.Python.3.12` или Microsoft Store (бесплатно, ~5 минут, один раз).
2. Дважды кликните `run_server.bat` (или `python wdpc_server.py`).
3. Сервер покажет IP компьютера, например `192.168.1.50`. При первом запуске Windows Firewall спросит про сеть — нажмите «Разрешить» (для частных сетей).
4. В приложении **WDPC Remote** на телефоне (тот же Wi-Fi): введите IP → «Подключить Wi-Fi».

## Что умеет
Alt+Tab / Alt+Shift+Tab, Task View (Win+Tab), Пуск, Alt+F4, Win+M, Win+D,
навигация стрелками по переключателю окон, Ping.

## Протокол (TCP, порт 8721)
```
KEY <vk> [DOWN|UP]     — клавиша Windows Virtual-Key code
CHORD <vk1> <vk2> ...  — аккорд (зажать, отпустить в обратном порядке)
PING                   — PONG
```

## Можно ли вообще без сервера на ПК?
Смартфон может выступать Bluetooth-HID-клавиатурой только если ОС телефона
это разрешает (обычно нет) либо через root-модули (Bluetooth HID Device,
KDE Connect не умеет HID). Поэтому на Windows минимально возможный «сервер» —
этот скрипт: он ничего не устанавливает, не требует прав администратора и
запускается одним файлом. Альтернатива без всякого софта на ПК — готовый
блютус-пульт «в железе» (например, телефон-приложение не поможет, нужен
USB/BT-донгл типа BadUSB-сценариев — но это уже другое устройство).
